# server/

This directory was generated by `maltego-transforms start` and is the transform server that
transformatron drives. Its original README described the SDK's starter project, whose example
modules are not here.

See the repository root [`README.md`](../README.md) for how to run, scaffold and test transforms,
and [`docs/transform-authoring.md`](../docs/transform-authoring.md) before writing one.
